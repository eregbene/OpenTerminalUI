# Backtest Metrics

Implemented metrics include total return, annualized return, annualized volatility, Sharpe, Sortino, Calmar, maximum drawdown, drawdown duration, win/loss rate, profit factor, expectancy, average win/loss, payoff ratio, trade count, exposure time, turnover, average holding period, best/worst trade, consecutive wins/losses.

Warnings are emitted for low trade counts and unavailable ratios, such as profit factor when there are no losing trades.
