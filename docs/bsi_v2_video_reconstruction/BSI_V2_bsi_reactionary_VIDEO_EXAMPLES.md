# BSI V2 Reactionary Video Examples

Source basis: original mentor videos 25-26.

## REACTIONARY_GOLDEN_01

Video 25, schematic.

- Setup: standard Order Flow MSS/MSB creates array 1.
- Confirmation: price mitigates array 1, pushes away, and creates array 2.
- Entry: array 2 only.
- Stop: just beyond array 2, with wider alternative shown.
- Target: opposing structure/liquidity.
- RR tool examples: roughly 2.48 to 9.29 while mentor adjusts.
- Key rule: array 2 does not need to break structure.

## REACTIONARY_GOLDEN_02

Video 26, GBPUSD 5m short.

- Setup: sweep then MSS creates first gray OB/FVG area.
- Confirmation: price reacts from array 1 and creates a second smaller inner box.
- Entry: second box.
- Stop: beyond second box / relevant high.
- Outcome: mentor narrates about 10R.
- Rule impact: confirms the second-box entry on a real chart.

## REACTIONARY_CONTINUATION_VARIANT

Video 25 continuation schematic.

- The same two-array confirmation applies to continuation/MSB or ABC-shaped movement.
- Not limited to reversal MSS setups.
- Entry remains array 2 after reaction away from array 1.
