# SMC Overlays

Backend overlay contract supports:

- horizontal level
- price zone
- swing marker
- structure label
- session range/reference
- event marker
- text evidence through tooltip fields

Frontend representative integration:

- Chart Workstation `SMC` toggle
- compact Market Structure inspector
- toggles for swings, BOS, CHoCH, MSS, liquidity, sweeps, FVG, order blocks, ranges and sessions

The backend is not coupled to Lightweight Charts internals.
