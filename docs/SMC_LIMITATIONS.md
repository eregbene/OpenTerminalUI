# SMC Limitations

Implemented concepts are deterministic but not universal truths. SMC terminology is contested, so the engine stores exact configuration and explanations.

Deferred:

- inverse FVG
- balanced price range
- breaker blocks
- mitigation blocks beyond order-block state transitions
- rejection blocks
- propulsion blocks
- full supply/demand taxonomy
- bid/ask volume imbalance
- footprint/order-flow inference
- complete screener/alert UI
- persistent database migrations for snapshots

The current engine is suitable for research features and overlays, not automated execution.
