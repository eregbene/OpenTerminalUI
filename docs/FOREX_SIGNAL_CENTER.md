# Forex Signal Center

The Forex page includes a Signal Center for deterministic paper candidates.

## Visible State

- active candidates
- awaiting confirmation
- approved
- rejected
- expired
- active paper trades
- paper P&L
- emergency disable state

## Candidate Cards

Cards show symbol, strategy, direction, timeframe, entry, stop, target, position size, estimated risk, risk/reward, confidence, framework agreement, regime, session, expiration and status.

## Review

The review area shows candidate ID, strategy, expiration, risk decision, margin estimate, OMS order lineage, regime, session, data quality and stored deterministic evidence.

## XAU/USD

For `XAUUSD`, the UI shows:

```text
Analysis available
Framework analysis available
Execution disabled until compatible spot or broker-backed contract is verified
```

## IBKR Paper Status

FX-5 adds compact IBKR status and contract cards showing connection state, masked account, market-data state, reconciliation, recovery, contract verification, `con_id`, and minimum tick.
