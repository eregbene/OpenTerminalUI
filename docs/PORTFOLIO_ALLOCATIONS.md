# Portfolio Allocations

Supported allocation types:

- `FIXED_CAPITAL`
- `PORTFOLIO_PERCENT`
- `RISK_BUDGET`
- `MAX_NOTIONAL`
- `MAX_MARGIN`
- `OBSERVATION_ONLY`

Allocation activation requires:

- Active portfolio.
- Approved deployment.
- Paper account.
- Sufficient capital.
- Explicit exposure, loss, and drawdown limits.
- No emergency block.

Allocation changes are versioned and authorization-gated.
