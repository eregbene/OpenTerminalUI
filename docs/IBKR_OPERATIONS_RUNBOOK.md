# IBKR Operations Runbook

1. Start TWS or IB Gateway in paper mode.
2. Confirm API is enabled.
3. Configure host, port, client ID and allow-listed paper account.
4. Connect from Broker Operations.
5. Verify account is labeled `IBKR PAPER ACCOUNT`.
6. Resolve a contract.
7. Check market-data mode.
8. Retrieve account snapshot.
9. Submit only through canonical OMS order actions.
10. Reconcile after every broker mutation.
