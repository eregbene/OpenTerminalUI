# Research Agent Plans

Plans persist the complete intended research before execution.

Plan statuses include:

- `DRAFT`
- `READY`
- `WAITING_APPROVAL`
- `APPROVED`
- `RUNNING`
- `PAUSED`
- `PAUSED_BUDGET`
- `COMPLETED`
- `FAILED`
- `CANCELLED`
- `EXPIRED`

Task graphs are validated for cycles, missing dependencies, unsupported task types and size limits.
