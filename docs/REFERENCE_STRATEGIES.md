# Reference Strategies

Phase 6 registers five reference strategies:

- `ema_trend_continuation_v1`: EMA alignment and candle confirmation.
- `rsi_mean_reversion_v1`: RSI oversold/overbought with candle confirmation.
- `donchian_breakout_v1`: close beyond the prior 20-bar Donchian channel.
- `smc_liquidity_reversal_v1`: liquidity sweep plus CHOCH/MSS and zone evidence.
- `smc_continuation_v1`: BOS continuation with imbalance/order-block evidence.

All reference strategies are research status and proposal-only.
