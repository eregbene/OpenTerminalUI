# Phase 12 Runbook

Startup:

1. Start Docker backend and Redis.
2. Confirm `/health`.
3. Create a Phase 12 paper portfolio.
4. Attach approved paper strategy deployments.
5. Add versioned allocations.
6. Persist snapshots and reports.

Incident response:

1. Review `/equity/operations`.
2. Inspect active alerts.
3. Acknowledge incidents.
4. Resolve only after the underlying component recovers.
5. Preserve incident timeline.
