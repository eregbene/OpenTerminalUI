# Research Agent Runbook

1. Confirm backend health.
2. Confirm `/api/ai/providers/health`.
3. Confirm `/api/research-agent/status`.
4. Create or activate a research policy.
5. Generate hypotheses from verified evidence.
6. Create a plan.
7. Review task graph, budget and approval requirements.
8. Approve manually when required.
9. Start plan.
10. Review reports, lineage and recommendations.

Use kill switches to block new work for a user, plan, provider, dataset, strategy pack or all autonomous research.
