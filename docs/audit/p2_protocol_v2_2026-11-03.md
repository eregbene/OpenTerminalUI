Written 2026-11-03 while P2 v1 (`bensim.audit_p2`, protocol p2_protocol_2026-11-03.md) was still running and **before any of its output was opened**. v1 stays on record as its own registered experiment. v2 changes only the Friday rule and adds portfolio-level analysis.

## Unchanged from v1
- The 8 strategies and their frozen parameter objects.
- Symbols: EURUSD, GBPUSD, USDJPY, USDCHF, USDCAD, XAUUSD.
- Period: 2026-08-03 → 2026-11-03 (exclusive).
- DB candles after the insert-only backfill. The Oct 27 21:30–21:50 gap is kept, not filled.
- Broker costs `observed_account`: observed spread, $0 commission, observed swap per lot-night; every cost labelled.

## Analysis
1. **Each strategy independently:** bensim.validate. Gross (after spread/slippage, before commission+swap) and net, PF, PSR, DSR (N = all registry trials), effective days, block-bootstrap CI, drawdown/recovery, by pair, session, month, D1 trend regime, D1 vol regime.
2. **Across the 8:** Holm-adjusted p (day-clustered t), PBO (CSCV, 8 blocks), correlation matrix of daily net R.
3. **Portfolios (equal 1R risk per trade):**
   - (a) all 8 independent sum;
   - (b) live set (fib618, imbalance, enigma, bennett) independent sum;
   - (c) live set under the live **one-trade-per-pair** rule (books.py): trades taken in entry-time order, a trade is skipped while any other live-set trade holds that symbol. Ties at the same timestamp go in the books.py order fib618, bennett, imbalance, enigma, because the confirmation score isn't reproducible from the backtest.
   - Each has: drawdown, max concurrent open trades, max open risk (R), max net exposure per currency (R units: +1 for the long currency, −1 for the short one, per open trade).
4. **Sensitivities** (reported, never used to choose): all Friday close; all weekends held; legacy costs.

## Recommendation rule (fixed now)
- **Retain (as a research candidate only):** DSR > 0.95 **and** Holm p < 0.05 **and** bootstrap P(total ≤ 0) < 0.05. It must also not contradict the longer-run evidence on file.
- **Investigate:** net expectancy > 0, PF ≥ 1.10 and bootstrap P(total ≤ 0) < 0.25, but fails the Retain test, or contradicts the longer-run evidence.
- **Reject:** everything else (net expectancy ≤ 0, or PF < 1.10, or P(total ≤ 0) ≥ 0.25).

A recommendation is advice only. Nothing is switched on or off.
