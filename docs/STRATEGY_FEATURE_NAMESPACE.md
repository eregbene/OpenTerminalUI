# Strategy Feature Namespace

Allowed feature prefixes:

- `price.`
- `indicator.`
- `structure.`
- `liquidity.`
- `fvg.`
- `order_block.`
- `dealing_range.`
- `session.`
- `market_data.`

Current indicator features include EMA, SMA, RSI, ATR, MACD histogram, Bollinger bands, stochastic, ADX, ROC, historical volatility, volume SMA, and Donchian channel levels.

Current SMC features are derived from the Phase 5 market-structure snapshot, including trend, BOS/CHOCH/MSS direction, liquidity sweeps, nearest liquidity levels, fair-value-gap presence, order-block presence, and dealing-range position.
